# Bilibili 详细笔记格式与分块细则

## 输出定位

默认生成中文为主、保留细节的详细分时笔记：标题清楚、元信息紧凑、开头先给内容概览，正文按时间轴展开，最后再做主题总结。

核心原则：宁可长、不可漏。不要只写“视频讲了 X、强调了 Y”这种无法帮助用户回看的概括。

## 推荐格式

```markdown
---
title: "<视频标题>"
date: "<YYYY-MM-DD>"
source: "<Bilibili 视频链接>"
bvid: "<BV号>"
creator: "<UP主>"
duration: "<mm:ss>"
subtitle_source: "官方字幕（AI识别）/ 官方字幕 / Whisper 转写（<model>）"
type: video-note
tags:
  - "<主题标签>"
  - "<主题标签>"
aliases:
  - "<可选的简短检索名>"
---

# <视频标题> [<分类，可选>] · 分时详细笔记

> 🔗 <视频链接> ｜ 👤 UP主：<author> ｜ ⏱ 时长：<mm:ss> ｜ 📝 文案来源：官方字幕（AI识别）/ Whisper 转写（<model>）

<一段内容概览：说明视频对象、背景、主要议题和核心结论。访谈可写嘉宾身份；课程可写课程名称和主题。>

## 一句话摘要 / One-Line Summary
- **中文**：一句话说清视频讲了什么。
- **EN**: One sentence capturing the video's essence.

## 分时概述 / Time-Stamped Notes

### [mm:ss–mm:ss] <分段标题>
- <保留人名、机构、数字、术语、例子、因果推理和关键原话>
- <每段通常 2–8 条；长视频宁可展开，不要压缩成空泛结论>

### [mm:ss–mm:ss] <分段标题>
- …

## 金句摘录 / Memorable Quotes

- “<原话>”（[mm:ss]）
- …

## 总体总结 / Overall Summary

- **对象/背景**：<视频讨论的对象和问题>
- **核心观点**：<跨时间的主要判断>
- **方法论/启示**：<方法、证据、限制或可迁移经验>
- **一句话收束**：<最终结论>
```

### 格式约定

- YAML frontmatter 是笔记的第一段内容，围在 `---` 之间；`date` 表示笔记生成日期，格式为 `YYYY-MM-DD`，使用生成时的本地日期。
- 必填属性为 `title`、`date`、`source` 和 `tags`。`bvid`、`creator`、`duration`、`subtitle_source`、`type` 和 `aliases` 按视频信息和检索需要填写；无法核实时省略，不猜测。
- `tags` 使用 YAML 列表，选择少量能概括视频主题的标签。带空格、冒号或特殊字符的字符串加引号；未提供可用 BV 号时省略 `bvid`。
- 第一行优先使用视频标题；分类路径只有在用户提供或上下文明确时才添加，不要擅自编造。
- 顶部元信息使用 emoji 风格：`🔗` 链接、`👤` UP 主或嘉宾、`⏱` 时长、`📝` 文案来源。
- 元信息下面先写一段自然语言概览，再进入摘要，避免用户只看到标题和要点列表。
- 中文为主。英文只保留专有名词、必要原文和 One-Line Summary；用户明确要求双语时，再给分时段逐段补充 EN。
- 分段依据话题转折、论证变化或问答主题，不按固定时长硬切；时间范围应覆盖视频全程并按顺序排列。
- 引号内容必须来自字幕/转写；AI 字幕明显错词时，可以在正文中按语境修正，但不要把推断写成原话。

## 文件命名与保存

用户指定外部笔记目录时，主文件保存到：

```text
<用户指定目录>/<中文标题>.md
```

工作区镜像默认保存到：

```text
output/<中文标题>.md
```

文件名直接使用标题或简短中文标题，不使用 `BV...-summary.md` 或 `av...-summary.md`。保留中文和必要的英文专名；清理路径分隔符、控制字符及不适宜字符，长标题可缩短但必须保留主题或嘉宾辨识度。目标已存在时追加 `-2`、`-3`，不要覆盖已有笔记。

参考命名：

```text
南京大学生成式软件工程1-欢迎来到未来.md
南京大学生成式软件工程2-提示词工程.md
姚顺宇4小时访谈.md
```

## 详细程度

- 短视频每个时间段保留 2–4 条，长视频每个时间段保留 4–8 条；依据内容复杂度调整。
- 保留具体数字、比例、时间、人名、公司、论文、书名、模型名、技术术语、案例和因果推理。
- 访谈要区分主持人提问与嘉宾回答，记录观点背后的理由和限定条件。
- 不要只保留观点而删除论据，也不要为了短而删除有助于理解的例子。

## 长文本分块

- 文本不超过 40,000 字符：直接处理。
- 超过 40,000 字符：按空行或自然段切分，每块不超过 12,000 字符，并保留该块的时间范围。
- 各块先独立生成分时概述，合并时按时间顺序串联，去重金句；总体总结必须在所有块阅读完后统一生成。
- 分块不会降低详细程度；长视频输出较长是正常结果。
