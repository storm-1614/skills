# Skills

## bili-video-summary
通过 bilibii 官方字幕接口、`ffmpeg` 关键视频帧提取来总结 bilibili 视频，并生成总结文章。  

> 灵感来自 jyy 的生成式软件工程课程。  

## pdf-translate
用 codex 本地桥接服务将英文学术论文 pdf 精翻成中文 pdf，质量极高。  
> ⚠️需要给 codex 对话 full access 权限，这样才能允许跑本地桥接服务。  


## artifact-template-docx
根据教材课后习题(计算机组成与系统结构)的课后习题 pdf，生成习题 Word 作业稿的 Skills，可用性很高，只需要再简单修改排版就能用。
